# CS-374-Drums-Sound
** Partners: William Grahame, Brian Jeffers, Karthik Reddy Akkala**

Our project targets musicians and aims to let them use audio interpretation to convert music files into physical notes. We chose direction B and will implement a music/live-coding language that can accept drum and wave files and convert portions of the file into a physical representation of the music. For our intended starter, we currently plan to explore and potentially use Python libraries such as PyDrumScore and Pytheory to interpret music files and allow them to breakdown the musical composition, and allow for us to parse the music effectively. 

We plan on building an audio player first to help us read and later produce an eventual output. For our major tasks, we currently anticipate having Brian establish the audio files and how to use them. Karthik plans on building out the Python code and creating a rough format and outline for interpretation and later documentation. William plans to also help with the documentation and further research on how to interpret the music effectively. We plan to check these positions by analyzing the input audio files and their readability and then further create an effective structure that can convert the files effectively.
