# CS-374-Drums-Sound
** Partners: William Grahame, Brian Jeffers, Karthik Reddy Akkala**

Our project targets musicians and aims to allow them to use audio interpretation and convert music files into physical notes. We decided to pursue direction B and implement a music/live-codeing language that can receive drum and wave files and then convert portions of the file into a physical representation of the music.
